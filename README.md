Personal Fork of DragonFixes; a crude attempt at trying to make DApi + Chromaticraft work in GTNH, courtesy of some AI work. Original description below:



# DragonFixes

Various fixes for issues found in some of Reika's mods.
[GTNHLib](https://github.com/GTNewHorizons/GTNHLib) and [UniMixins](https://github.com/LegacyModdingMC/UniMixins) required.

Most credit goes to [gamrguy](https://github.com/gamrguy) a.k.a. "RobotLucca" a.k.a. "thegamemaster1234" for creating the original ASM-based ChromatiFixes

Fixes:
- Disables the WAILA handlers for IFluidHandlers from Reika's mods, as WAILA provides its own handler for these (unilock)
- Ars Magica 2 (optional, temporarily hosted here)
  - Guards missing AM2 extended player properties in `ShrinkHandler#onEntityLiving`, preventing simulated-player crashes during GuideNH/BlockRenderer6343 scans without disabling shrinking for initialized players.
- CaveControl
  - Prevents `CaveLoader#getEffectiveBiome` from ever returning a null biome, fixing crashes usually caused by pylon chunk loading (thegamemaster1234)
- World-generation performance and compatibility
  - Cave/ravine biome memoization, bounded cliff-neighborhood scanning and native biome-cache tile reuse are always enabled where applicable. They retain the original carving and cliff shaping rules.
  - Nature's Compass uses saved and pending biome data before generator prediction for supported ChromatiCraft biomes when the corresponding integration is enabled.
  - Pylon cache synchronization and thread-local ray tracers replace the old crash-workaround variants.
  - `general.optimizeRtgEndlessIdsMapGen` (default false) restores one map-generation pass per distinct biome in ascending ID order. Enable for new worlds; older chunks generated by EndlessIDs' repeated loop may differ.
  - `general.enableWorldStartupProfiler` remains opt-in for performance investigations. Temporary biome-registration, selection and first-generation probes were retired; earlier implementations are available in Git history.
- ChromatiCraft
  - Live-adjustable `visual.artefactZoneShaderStrength` (default `0.25`) softens the Unknown Artefact zone edge-glow shader; `0` disables it and `1` restores the original effect (client-side, no restart). Existing `general` values are automatically migrated.
  - New `visual.artefactZoneGlowBrightnessCeiling` (default `0.65`) caps the added UAZONE highlight brightness without darkening the original scene. Live-adjustable, separate from shader strength; `1.0` restores the original peak.
  - Prevents crashes in `ChromaClientEventController#updateGlowCliffRendering` (thegamemaster1234)
  - Fixes the loadTransferRects method in a few NEI handlers, making them able to load with GTNH!NEI (FlamingKetchup)
  - Adds support for Xaero's maps where appropriate (unilock)
  - Caches the world directory path used during dungeon generation to make it much faster (FlamingKetchup)
  - Ignores the order progress was made in `ProgressionManager#isProgressionEqual` (unilock)
  - Prevents random ConcurrentModificationExceptions during pylon overlay rendering (thegamemaster1234)
  - Prevents the Lumen Beacon from interfering with itself (thegamemaster1234)
  - Enable Lumen Alveary Humidity and Temperature controls when the Princess is unable to work (as these are designed to allow the Princess to work in the first place) (thegamemaster1234)
  - Allows Cave Crystals and Potion Crystals to work with the Player Imitation Core, even if the player isn't in the immediate vicinity (unilock)
  - Prevents crashes caused by Adjacency Cores on neighbor state updates (thegamemaster1234, unilock)
- DragonAPI
  - Isolates world-generation block interception batches by generation thread and world, rejecting unrelated client writes, preserving registered exceptions and ordered immutable watcher snapshots, and guarding reentrant population dispatch. Galacticraft's existing exclusion is evaluated when recording begins rather than for every block change.
  - Prevents NullPointerExceptions caused by `AbstractSearch$FoundPath#getPath`, preventing ChromatiCraft's Bezier Crystals from causing an Internal Server Error (unilock)
- RotaryCraft
  - With `replaceRubberWithGemLatex` enabled, the Drying Bed produces latex instead of rubber, which is apparently helpful when playing with HBM's NTM (unilock)
  - Allows the Bedrock Breaker to break both types of Fractured Bedrock from Factorization (unilock)
- Satisforestry
  - Prevents a ClassCastException when removing a Slug item from slot 39 of any non-player inventory (unilock)
  - Allow Pressurizer multiblock to receive RotaryCraft power via Power Hub (thegamemaster1234)
- Void Monster
  - With `disableVoidMonsterHardcode` enabled, disables the hardcoded checks for Void Monster spawning in certain dimensions, instead always respecting the config (unilock)
- DragonRealmCore
  - With `disableTickInterceptASM` enabled, forcibly disables DragonRealmCore's "TickIntercept" class transformer - this prevents DRC's "PAUSEOFFLINE" config (disabled by default!) from functioning, but fixes compatibility with GTNHLib 0.6.19+ (unilock)
  - With `disableTerritoryStrongholdSystem` enabled, disables the TerritoryStrongholdSystem (unilock)
  - Prevents NullPointerExceptions caused by Hex Generators (thegamemaster1234)
  - With `energizationManagerFix` enabled, prevents crashes in `EnergizationManager#getEnergizationLevel` (however, the chosen fix prevents playing with the "Atmospheric Permeability Mediation" mechanic) (thegamemaster1234)
